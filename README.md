# Órbita · Quiz espacial

Cuestionario interactivo en español sobre exploración espacial. Incluye diez preguntas, seguimiento de puntuación y progreso, comentarios animados para cada respuesta y una pantalla final con una reacción según el resultado. La interfaz se adapta a los temas claro y oscuro del sistema y respeta la preferencia de movimiento reducido.

## Ejecutar localmente

Abre `index.html` directamente en un navegador. No necesita servidor, compilación, instalación ni dependencias externas.

## Publicación

GitHub Actions publica el sitio estático en GitHub Pages al actualizar la rama `main` o al iniciar manualmente el flujo de trabajo **Deploy to GitHub Pages**. El sitio se sirve desde `index.html`; no hay una etapa de compilación.
